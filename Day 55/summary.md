## Day 55 – HTML & URL Parsing in Flask (Higher Lower Game)

- Learned how to create dynamic URLs in Flask using route parameters
- Used `<variable>` syntax in Flask routes to capture values from the URL
- Understood type converters in routes (e.g. `<int:number>`)
- Built a simple Higher Lower guessing game using Flask
- Implemented conditional logic based on URL input
- Returned different HTML responses depending on user guesses
- Practiced embedding HTML directly inside Flask return statements
- Used basic inline CSS and HTML tags for visual feedback
- Strengthened understanding of how Flask parses URLs and maps them to Python functions
- Connected backend logic with user interaction through the browser
